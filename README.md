# Adriano Gallo — Portfolio

Portfolio produit d’Adriano Gallo, AI Engineer spécialisé en LLM, RAG, agents IA et NLP.

## Développement

```bash
pnpm dev
pnpm lint
pnpm typecheck
pnpm build
```

L’adresse email et le dépôt GitHub du projet principal sont configurés dans les données du site. Après déploiement, renseigner `NEXT_PUBLIC_SITE_URL` dans `.env.local` ou dans les variables Vercel afin de produire le canonical et les URLs sociales absolues.

Les fondations sont documentées sur `/design-system`. L’étude de cas principale est disponible sur `/projets/football-intelligence-assistant`.
